Chai is a Python program

The idea

A chai recipe and a Python program work the same way.

The ingredients (water, milk, tea leaves, sugar) are variables: a name with a value stored in it.

The recipe is a function: write the steps once, run them whenever you want.

"Keep heating until it boils" is a while loop: the work repeats as long as the condition is true.

The code

paani = "1 cup"
cheeni = 1

temp = 20
while temp < 100:
    temp = temp + 20      # keep heating
print("Chai ready!")

Output:

Chai ready!

Try it yourself

  • Create 4 variables for the ingredients of your favourite chai.
  • Change temp + 20 to temp + 40. How many times does the loop run now?
