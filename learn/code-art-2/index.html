Neon titli: ek equation

Code art with Raj, notes 2. One equation, 18 lines of Python, and a glowing neon butterfly. Then we change one number and watch the wings. Free, simple English.

The idea

There is a famous curve called the butterfly curve. Temple H. Fay found it in 1989. It is drawn from one equation in polar form: for every angle t, the equation gives a distance r from the centre. Join all the points and a butterfly appears.

The classic equation is r = e^cos(t) − 2·cos(4t) + sin⁵(t/12), with t going from 0 to 12π. Our code writes the "2" as a number called K, so we can change it.

Important: K = 2 is the butterfly curve by Fay. The other K values (4, 1, 0.5, 0) are our own experiments on this page. They are not Fay's curve.

The code: butterfly.py

You need Python and Pillow (pip install pillow). Make a folder called frames next to the file first (mkdir frames), because the code saves the pictures there. The file has 18 real code lines, plus comments.

# Neon butterfly from ONE equation (our own code). Polar butterfly curve, T. H. Fay (1989):
#   r = e^cos(t) - K*cos(4t) + sin(t/12)^5      <- K is the "one number" we will change
import math
from PIL import Image, ImageDraw, ImageFilter, ImageChops

def butterfly(k=2, size=1080, name="butterfly"):
    sc = 0.105 if k <= 2 else 0.082                      # smaller scale so big wings still fit
    pts = []
    for i in range(0, 24000):
        t = i * 12 * math.pi / 24000                      # t from 0 to 12*pi
        r = math.exp(math.cos(t)) - k * math.cos(4 * t) + math.sin(t / 12) ** 5
        pts.append((size / 2 + r * math.sin(t) * size * sc, size * 0.46 - r * math.cos(t) * size * sc))
    glow = Image.new("RGB", (size, size), "black")
    ImageDraw.Draw(glow).line(pts, fill=(255, 40, 200), width=7)
    neon = Image.new("RGB", (size, size), "black")
    for radius in (40, 18, 8):                            # layered blur = neon glow
        neon = ImageChops.add(neon, glow.filter(ImageFilter.GaussianBlur(radius)))
    ImageDraw.Draw(neon).line(pts, fill=(255, 230, 255), width=2)   # thin bright core
    neon.save(f"frames/{name}.png")

for k in (2, 4, 0.5):
    butterfly(k, name=f"butterfly-K{k}")

Run it: python butterfly.py. It saves three pictures in frames, for K = 2, 4 and 0.5.

How it works

  • The loop takes 24,000 tiny steps of t from 0 to 12π. At each step it works out r with the equation.
  • r * sin(t) and r * cos(t) turn that distance and angle into x and y on the picture.
  • The neon look: draw the line thick in pink, blur it three times with different sizes, add the blurs together, then draw a thin bright line on top.
  • sc is only a scale, so the bigger wings (K above 2) still fit in the picture.

The experiment: change K

To get all five pictures below, change the for line at the bottom to for k in (2, 4, 1, 0.5, 0): and run it again. Everything else stays the same.

So the number in front of cos(4t) is what makes the wings. Make it smaller and the wings shrink. Make it bigger and they grow. At zero they are gone.

Try it yourself

  • Try K = 3, then K = 6. When do the wings start to overlap?
  • Change the 4 in cos(4 * t) to 3, then 5. What happens to the number of wings?
  • Change the pink colour (255, 40, 200) to blue or green for a different neon.

Remember

A drawing can come from one equation. Change one number, K, and you get a different drawing. The sources say the sin⁵(t/12) part was added mainly to make the picture look nicer.
