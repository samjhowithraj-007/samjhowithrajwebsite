The code

import random

for i in range(1, 4):
    chai = random.choice(["Masala", "Adrak"])
    print(f"Cup {i}: {chai}")

Output:

Cup 1: Adrak
Cup 2: Masala
Cup 3: Masala
(random: your cups will be different)

Try it yourself
