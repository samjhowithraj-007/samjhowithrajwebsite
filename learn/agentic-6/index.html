Memory: write it down, read it next time

Agentic AI with Bunty, lesson 6 of 6. simple English notes, free.

Open the interactive lesson

The idea

Last time Bunty planned Mummy's birthday party. A week later Raj said: "Bunty, order the cake." Bunty asked: "Sir, which cake?"

Raj had told him last time: Mummy loves chocolate cake. But Bunty forgot, because he had no memory. Every task started from zero.

So Raj gave Bunty a diary. Now Bunty writes down the important facts, and reads the diary before the next task.

  • Write: "Mummy likes chocolate cake. Balloons can be ordered online."
  • Next time, before starting, Bunty reads the diary.
  • Result: "Sir, chocolate cake ordered! And the balloons online too."

Try it yourself

  • Think of a helper (an app, a friend, an assistant). What one thing should it remember about you?
  • Write 3 lines for Bunty's diary about a party you plan every year.
  • What should Bunty NOT write in the diary? (Think: passwords, private things.)

Remember

An agent's memory: write the important things down, and read them next time. Next: Part 7, Bunty gets helpers.
